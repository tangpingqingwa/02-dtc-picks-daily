# DTC Picks Daily

Daily public auction for the cover slot of a DTC / Shopify / Amazon picks brief. Suppliers bid whole USD so sellers see their product link first this morning.

Build contract: [SPEC.md](./SPEC.md).
How we work: [CONTRIBUTING.md](./CONTRIBUTING.md). `main` stays buildable and testable.
How we build: [BUILD.md](./BUILD.md) — stack, modules, tests, PR sequence.

No ads. No API keys. No revenue share. Rank is the bid. Minimum $5. Cover resets daily at 00:00 UTC (override with `BOARD_TZ`).
